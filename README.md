# Squishyy — Squishy Shop

Website toko squishy dengan tema pink & putih, dibuat untuk langsung di-upload ke GitHub.

## Isi
- `index.html` — struktur website
- `style.css` — desain responsive
- `script.js` — filter produk, keranjang, dan checkout WhatsApp

## Cara upload ke GitHub
1. Buat repository baru di GitHub.
2. Upload `index.html`, `style.css`, dan `script.js`.
3. Buka **Settings → Pages**.
4. Pilih branch utama sebagai source.
5. Simpan dan tunggu GitHub Pages aktif.

## Catatan
Checkout WhatsApp menggunakan link umum `wa.me`. Ganti bagian `https://wa.me/?text=` di `script.js` dengan nomor WhatsApp toko jika ingin langsung menuju nomor tertentu.
